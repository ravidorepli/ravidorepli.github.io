shorts-bot privacy policy

shorts-bot is a personal tool used only by its owner to post the owner's own original videos to the owner's own YouTube channel, Instagram account and TikTok account.

YouTube API Services

shorts-bot uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data handled through YouTube API Services: https://policies.google.com/privacy.

TikTok

shorts-bot uses TikTok Login Kit and the Content Posting API with the scopes user.info.basic, video.upload and video.publish. It reads only the owner's basic TikTok profile info (open id and display name) to confirm the right account is connected, and uses the posting scopes only to upload the owner's videos to the owner's TikTok account. Access can be revoked at any time in the TikTok app under Settings and privacy → Security → Apps and services.

Instagram

shorts-bot uses the Instagram Graph API content publishing permission only to publish the owner's videos to the owner's Instagram account.

Data

It uses the YouTube upload permission solely to upload the owner's videos. It does not collect, store, share or sell data about any other person. Access tokens are kept as private secrets by the owner and are not disclosed to anyone. No YouTube, Instagram or TikTok data is retained beyond the uploads themselves.

Revoking access

Access can be revoked at any time at https://security.google.com/settings/security/permissions.
